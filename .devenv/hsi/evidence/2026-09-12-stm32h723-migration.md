# STM32H723 migration and target evidence — 2026-09-12/13

Historical record, superseded by the [550 MHz campaign](2026-09-13-stm32h723-550mhz.md).
The original 480 MHz plan used a 960 MHz VCO, exceeding the H723 wide-VCO
limit of 836 MHz. The results below record observed execution, not compliant
clock operation. The current 550 MHz plan uses a 550 MHz VCO within the limit.
Board V1.2 and the fitted LCD were subsequently confirmed by the owner.
The current smoke-test script now checks the 550 MHz configuration.

The WeAct STM32H723VGT6 migration passed debug and release tests through the
attached Atmel-ICE. Both builds survived normal scheduler/watchdog operation,
recovered from deliberately omitted watchdog servicing, and drove PE3 high and
low. The final release image was resumed on the board.

At the final debugger disconnect, the release image had reached 35,711 PFM
cycles since the injected reset, with diagnostic `None` and SHCSR/CFSR/HFSR
still zero. The core was resumed before OpenOCD was shut down.

The campaign began on September 12 and continued after midnight September 13
in Europe/Berlin. The filename retains the campaign start date.

## Migration changes

- Internal flash reduced to 1 MiB; AXI SRAM to 320 KiB; D2 SRAM to 32 KiB;
  D3 SRAM to 16 KiB. ITCM remains 64 KiB, DTCM 128 KiB and backup SRAM 4 KiB.
  The default shared AXI/ITCM allocation is retained.
- The reset entry selects the internal LDO and waits for `ACTVOSRDY` in naked
  assembly before a compiler-generated stack frame or RAM writes. Both debug
  and release disassembly were inspected for this ordering.
- The vector table now has 163 external entries, covering IRQ 0–162, plus the
  16 core entries including MSP: 179 entries / 716 bytes. The table is copied
  to 1024-byte-aligned DTCM and `VTOR` is updated.
- Power uses direct H723 VOS0. The H743 SYSCFG overdrive interface was removed.
  `FLASH_ACR` uses three wait states and programming-delay encoding 3, as
  specified by RM0468 Rev. 3 Table 16, p.161 for 240 MHz AXI at VOS0.
- The 25 MHz HSE / 5 × 192 / 2 clock plan retains CPU 480 MHz, AHB 240 MHz
  and APB 120 MHz. Initialization explicitly switches to ready HSI before
  reconfiguring PLL1.
- The heartbeat output is PE3, active high. USART1 remains PA9/PA10, 115200
  8N1, with the H723 USART16910 kernel-clock selector.
- WWDG1 enables `RCC_GCR.WW1RSC` at each startup to request a full system reset.
- The debugger uses the H723 single-bank target and the STM32H723 SVD from
  Open-CMSIS-Pack DFP v4.1.3. `memory.x` specifies the Reset entry; `build.rs`
  makes linker-script changes trigger a rebuild.

## Reproducible campaign and results

Commands are in the [board documentation](../../STM32H723VGT6/README.md#build-and-hardware-test).
The retained [GDB script](../../STM32H723VGT6/smoke-test.gdb) programs the ELF,
compares all loadable sections, runs for 30 seconds, inspects state, resumes
for two more seconds, then injects an interrupt stall by setting PRIMASK.
The debug server freezes watchdog counters only while the core is halted.
After the deliberate reset the script verifies continued task progress and
samples PE3 across another heartbeat cycle. The firmware contains no test-only
task instrumentation.

Small differences between host wait duration and scheduler time include host/
debugger latency and SysTick reprogramming pauses. These counts demonstrate
progress; they are not a calibrated clock-frequency or wall-clock drift test.

## Fault found and corrected

The initial omitted-service test produced `RCC_RSR=0x10000000`, but startup
stalled trying to disable PLL1 while it still supplied SYSCLK. The cause was
missing `RCC_GCR.WW1RSC`, inherited from the previous board setup. RM0468
Rev. 3 pp.347 and 426 require this bit before WWDG1 enable and state that
enabled behavior is not guaranteed with the bit clear. Setting it produced
the complete WWDG/pin/CPU reset flags `0x10420000` and successful restart in
both builds. The explicit HSI transition also makes clock initialization
tolerate a previously active PLL, following RM0468 pp.331 and 363.

These are bring-up and regression tests on one powered board. UART pin/baud
configuration was checked, but no external serial loopback, oscillator
measurement, power-cycle test, peripheral load test, full PFM fault campaign,
or repeat of the former board's FPU stress/cycle-boundary campaign was made.
External flash, USB, SD, TFT and camera drivers remain outside the existing
firmware's implemented scope. Historical H743 timing measurements do not
qualify H723 timing margins. PCB revision/population and optional connector
continuity require physical inspection if those interfaces are to be used.
