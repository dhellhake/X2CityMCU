# Accelerator position identification requirements

**Draft addition — 2026-09-18.** **Type:** System Requirement. **Target:** [LE-ACCELERATOR](../../ARCH-001_System_Architecture.md#le-accelerator).

`AcceleratorPosition` has exactly two semantic members: `Position` and `Qualification`. `Position` contains normalized travel, physical-rest status, and its actual measurement time. `Qualification` carries authoritative usability and source-health information.

| ID | Requirement | Derived from | Related / governing contracts | Planned verification / acceptance |
|---|---|---|---|---|

| <a id="req-sys-acc-004"></a>`REQ-SYS-ACC-004` **Draft** | `LE-ACCELERATOR` shall express each qualified physical accelerator input in `Position` as normalized mechanical travel of 0 percent at fully released travel and 100 percent at full application, with physical-rest status according to the calibrated rest criterion. | [REQ-SYS-ACC-001](#req-sys-acc-001) | Rest criterion, endpoint uncertainty, and normalization acceptance: `WS-OI-002`. | `T-SYS`: stimulate released, full-application, intermediate, and rest inputs; verify normalized value and rest status. |
