# Accelerator position identification requirements

**Draft addition — 2026-09-18.** **Type:** System Requirement. **Target:** [LE-ACCELERATOR](../../ARCH-001_System_Architecture.md#le-accelerator).

`AcceleratorPosition` is the system interface record. Its semantic members are exactly `Position` and `Qualification`; inherited envelope metadata carries source and configuration identity, and `Position` carries the actual measurement time. These record definitions are normative through the requirements below.

“Derived from” contains only formal System Requirement parents. Open issues and allocation dependencies appear separately so that they do not create false derivation edges.
