# Accelerator position processing requirements

**Draft addition — 2026-09-18.** **Type:** Abstract Software Requirement. **Target:** [LE-ACCELERATOR-QUAL](../../../ARCH-001_System_Architecture.md#le-accelerator-qual).

The software contribution consumes `AcceleratorMeasurement` and produces the `AcceleratorPosition` record defined by [REQ-SYS-ACC-001](../AcceleratorPositionIdentification_Requirements.md#req-sys-acc-001). `executionTimeIn` is the caller-supplied evaluation-time reference. Publication/context validity describes the current record envelope; measurement qualification describes whether the contained `Position` may be used.

“Derived from” contains only formal System Requirement parents. Same-layer interfaces, compiled calibration, and time-source dependencies appear under “Related / governing contracts.”
