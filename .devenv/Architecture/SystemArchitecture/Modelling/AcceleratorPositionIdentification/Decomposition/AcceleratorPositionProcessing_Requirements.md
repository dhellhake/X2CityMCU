# Accelerator position processing requirements

**Draft addition — 2026-09-18.** **Type:** Abstract Software Requirement. **Target:** [LE-ACCELERATOR-QUAL](../../../ARCH-001_System_Architecture.md#le-accelerator-qual).

`executionTimeIn` is the caller-supplied evaluation-time reference. The software contribution creates `AcceleratorPosition`; Position is usable only when its Qualification permits it.

| ID | Requirement | Derived from | Related / governing contracts | Planned verification / acceptance |
|---|---|---|---|---|

| <a id="req-sys-acc-017"></a>`REQ-SYS-ACC-017` **Draft** | `LE-ACCELERATOR-QUAL` shall preserve the actual acquisition time for each accepted valid new measurement, including a same-value acquisition. | [REQ-SYS-ACC-001](../AcceleratorPositionIdentification_Requirements.md#req-sys-acc-001), [REQ-SYS-ACC-007](../AcceleratorPositionIdentification_Requirements.md#req-sys-acc-007) | Input evidence: `REQ-SYS-ACC-014`; caller time: `REQ-SYS-PLT-002`; publication or receipt time is not an acquisition-time substitute. | `T-SW`: compare same-value acquisitions, health-only publications, and invalid republishes; verify only a valid new acquisition updates the retained actual acquisition time. |

| <a id="req-sys-acc-038"></a>`REQ-SYS-ACC-038` **Draft allocation** | After normal or unexpected controller startup, `LE-ACCELERATOR-QUAL` shall withhold `Position` until successful current startup checks and a new valid measurement are available. | [REQ-SYS-ACC-026](../AcceleratorPositionIdentification_Requirements.md#req-sys-acc-026) | Initial qualification is not automatically a recognized fault. | `T-SW`: verify old evidence cannot establish Position. |
