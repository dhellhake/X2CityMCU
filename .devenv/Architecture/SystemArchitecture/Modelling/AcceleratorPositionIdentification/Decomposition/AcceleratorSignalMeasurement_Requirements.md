# Accelerator signal measurement requirements

**Draft addition — 2026-09-18.** **Type:** Abstract Hardware Requirement. **Target:** [LE-ACCELERATOR-HW](../../../ARCH-001_System_Architecture.md#le-accelerator-hw).

`AcceleratorMeasurement` is the evidence record passed to the software contribution: measured signal value, source identity, and measurement-integrity status. Its integrity status conveys whether evidence is usable; it does not prescribe distinct hardware encodings for every nonusable cause. The hardware allocation has no firmware timestamp, reset-policy, or semantic-position-qualification responsibility.

“Derived from” contains only formal System Requirement parents. Same-layer interface dependencies and open parameter gates appear separately.
