# TractionHardware requirements

**Draft successor allocation — 2026-10-02.** **Type:** Abstract Hardware Requirement. **Target:** `LE-TRACTION-HW`, realized by the traction power/interface hardware.

TractionHardware provides physical actuation and its physical evidence. HC-TRACTION-POWER/HC-INPUT-FE can support both TractionHardware and the independent MotorSignalMeasurement role, but there is no logical `LE-TRACTION-HW` Hall/current/bridge-observation feed. `LE-MOTOR-SIGNAL` exclusively owns that measurement evidence. The independent hardware shutdown path remains distinct from a software zero command and from evidence of the physical output.
