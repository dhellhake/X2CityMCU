# HMI control requirements

**Type:** System Requirement. **Target:** `LE-HMI-CONTROL`. **Status:** Draft allocation of retained approved vehicle requirements.

`LE-HMI-CONTROL` composes the supplied VD18MT display-supply/UART boundary and the project information-processing function. It exchanges settings and rider-information records with the external display; its electrical leaf conditions the switched pin-5 on/wake voltage for a compatible `LE-COMPUTE-HW` wake input under [REQ-SYS-HMIE-002](Decomposition/HmiElectricalInterface_Requirements.md#req-sys-hmie-002). The wake path does not require UART or running application code and does not grant drive permission. This function does not own Session authority, Session fault/report retention, normal-light policy, or lamp actuation. Each information exchange carries its semantic value and its qualification in one record; invalidity is published as invalidity. Initial state, transport activity, or a transmitted report never establishes a received setting or display acknowledgement.

The confirmed VD18MT device reference remains project-independent. Its historical implementation is evidence only. Selected-unit identity, connector electrical limits, timing, UART transport limits, display presentation, speed-status fallback and period remain open acceptance work under `WS-OI-008`/`009`. Pin-5 conditioning, wake-input compatibility, selected deep-sleep mode and electrical characterization are traced by [REQ-SYS-HMIE-002](Decomposition/HmiElectricalInterface_Requirements.md#req-sys-hmie-002) and [REQ-SYS-CMPH-001](../ComputeHardware_Requirements.md#req-sys-cmph-001).
