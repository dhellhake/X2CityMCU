# HMI electrical interface requirements

**Type:** Abstract Hardware Requirement. **Target:** `LE-HMI-ELECTRICAL`. **Status:** Draft.

This leaf owns the vehicle-side VD18MT display-supply, UART compatibility and power-lock conditioning boundary. The fixed five-wire physical bundle comprises common ground, display supply, two UART signals and pin 5 switched power lock. Pin 5's switched voltage is conditioned to a level compatible with the selected MCU wake input and connected to `LE-COMPUTE-HW` under [REQ-SYS-HMIE-002](#req-sys-hmie-002). This is an on/wake request from deep sleep; it neither grants Ready/drive authorization nor substitutes for the common startup guard. The established switch-off requirements remain in force; pin-5 deassertion response and MCU sleep-entry mechanism remain open. This leaf does not implement an MCU-controlled UART on/off function or claim that an outgoing report was acknowledged by the display.
