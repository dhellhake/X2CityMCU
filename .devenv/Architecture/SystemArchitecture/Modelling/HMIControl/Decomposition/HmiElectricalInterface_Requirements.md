# HMI electrical interface requirements

**Type:** Abstract Hardware Requirement. **Target:** `LE-HMI-ELECTRICAL`. **Status:** Draft.

This leaf owns the vehicle-side VD18MT display-supply, UART compatibility and power-lock conditioning boundary. The fixed five-wire physical bundle comprises common ground, display supply, two UART signals and pin 5 switched power lock. Pin 5's asserted on/wake signal is conditioned to a level compatible with the selected MCU wake input and connected to `LE-COMPUTE-HW` under [REQ-SYS-HMIE-002](#req-sys-hmie-002). While awake, this leaf publishes `HmiPowerLockObservation` state and integrity under [REQ-SYS-CMPH-002](#req-sys-cmph-002); HMI information processing owns its qualified On/Off interpretation. The intended physical Inactive-to-Off mapping remains Draft pending selected-unit compatibility and qualification; it is not a measured pin-5 fact. Wake or Off recognition neither grants drive authorization nor substitutes for the common startup guard. HMI UART loss alone shall not create Off. This leaf does not implement an MCU-controlled UART on/off function or claim that an outgoing report was acknowledged by the display.
