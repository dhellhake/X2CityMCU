# Compute requirements

**Type:** System Requirement. **Target:** `LE-COMPUTE`. **Status:** Draft.

This composite contains the hardware wake/observation boundary and the software platform binding. SessionPolicy owns operation lifecycle, Ready, fault lifetime and riding authority. A Compute request or sleep handoff does not establish physical output safety or remove residual/generated energy.

## Allocation

Compute receives the conditioned controller wake signal through [HMIControl](../DriverInteraction/Decomposition/HMIControl/HMIControl_Requirements.md), while [HMI electrical](../DriverInteraction/Decomposition/HMIControl/Decomposition/HmiElectricalInterface_Requirements.md) publishes its awake observation and [HMI information processing](../DriverInteraction/Decomposition/HMIControl/Decomposition/HmiInformationProcessing_Requirements.md) derives the qualified operation request for SessionPolicy. Runtime initialization and validation/execution of the guarded sleep handoff remain allocated to [Platform](Decomposition/Platform_Requirements.md). Qualified Off closes the operation session under [REQ-SYS-CTL-005](../../../../Requirements/Abstract_Software_Requirements/Settings_and_Control_Policy.md#req-sys-ctl-005); SessionPolicy alone grants/revokes sleep eligibility under [REQ-SYS-CTL-006](../../../../Requirements/Abstract_Software_Requirements/Settings_and_Control_Policy.md#req-sys-ctl-006), using the current traction evidence in [REQ-SYS-TRQACT-003](../Traction/Decomposition/TractionControl/Decomposition/MotorControl_Requirements.md#req-sys-trqact-003). Compute does not consume the HMI request or traction evidence for eligibility. Physical output and energy behavior remain subject to [REQ-SYS-TRQHW-004](../Traction/Decomposition/TractionControl/Decomposition/TractionHardware_Requirements.md#req-sys-trqhw-004) and [REQ-SYS-ENE-002/003](../../../../Requirements/System_Requirements/Energy_and_Protection.md#req-sys-ene-002)–003.
