# DRV8300DRGE-EVM integration and requirements fit

**Draft 0.2 — 2026-09-14.** This is the canonical project-specific integration record for the owner-selected **DRV8300DRGE-EVM** traction-power board.  It uses the retained EVM schematic/BOM and TI documentation; those source artifacts remain the authority for the assembled board.  It selects this fixed board as the starting implementation of `HC-TRACTION-POWER`.  It does not select a vehicle controller, an adapter PCB, a protection circuit, motor calibration, operating limit, or completed vehicle acceptance.

## Configuration and source boundary

| Subject | Fixed fact or controlled boundary |
| --- | --- |
| Board | Owner-owned, unmodified TI `DRV8300DRGE-EVM`; actual PCB/assembly revision and jumper positions are not yet recorded. The retained Variant-001 BOM and `MD030A(001)` schematic at [vendor artifacts](../../DRV8300DRGE-EVM/README.md) define the inspected reference configuration, not a measured as-held-board configuration. |
| Board supply and connector | `PVDD` is 6–100 V on J4; the board has a 30-A fuse and 32-A input connector. TI specifies 25-A continuous drive current under software limit and advertises 30-A peak. These are EVM facts, not vehicle limits. |
| Gate driver | DRV8300DRGE is a six-input, external-NMOS three-phase gate driver. On this EVM `MODE` is non-inverting (R7 DNP), the three-PWM jumper path is DNP and R4 sets about 215-ns typical dead time (150–280 ns tolerance). Its recommended `SHx` operating maximum is 85 V (110 V absolute maximum), so the EVM's 100-V input statement does not prove operating transient margin at the driver. The selected 14S pack outer cell-test reference is 58.8 V, not a normal 80%-SOC operating point or a regeneration transient limit. |
| Host | TI's intended host is the `LAUNCHXL-F280049C`; the EVM headers/pinout do not mate directly to the owner-selected WeAct STM32H723VGT6 vehicle host. A project host/adapter must map the six PWM inputs, three current outputs, PVDD/GVDD/board-temperature outputs, Hall signals and returns, and must control reset/boot Hi-Z behavior. The selected WeAct board does not itself establish the adapter, pin matrix, electrical levels or acceptance. |
| Energy system | The fixed 14S5P 35E bank has 50.4-V nominal voltage, 40-A ideal continuous discharge and 10-A ideal charge ceilings. DC battery current is distinct from phase current. The EVM's 25-A continuous condition therefore constrains the initially available traction envelope; it neither grants 40-A pack discharge nor establishes motor torque. |

Primary sources: TI [EVM user's guide](https://www.ti.com/lit/pdf/slvubv6), TI [DRV8300 datasheet](https://www.ti.com/lit/ds/symlink/drv8300.pdf), and the locally retained schematic/BOM.  The TI reference firmware is sensored trapezoidal; it is not the selected Hall-sensored FOC firmware.

## Board capabilities and explicit non-claims

| Function | EVM evidence | Integration disposition |
| --- | --- | --- |
| Bridge/PWM | Three complementary NMOS half bridges; six independent driver inputs and cross-conduction prevention. The populated R4 `DT`-to-ground setting has 150–280 ns dead time (215 ns typical) in the DRV8300 Rev-D specification. | A host must generate centre-aligned complementary SVPWM, including timing/dead-time verification and reset-safe pin policy. The driver has no system enable or `nFAULT` output to infer. |
| Phase current | Three low-side 3-mΩ shunts, 10-V/V CSA gain; default 1.65-V bidirectional offset. This is 30 mV/A, so the nominal analogue output is `1.65 V ± 0.030 V/A`; ±25 A corresponds to 0.90–2.40 V. The mathematical ±55-A span to 0–3.3 V is not an EVM operating rating. | Three channels support the selected FOC topology. Scale, polarity, amplifier/ADC range, simultaneous/synchronous sampling, conversion latency and every modulation-valid window require host/board measurement. A reconstructed third phase is derived feedback, never a substituted sensor channel. |
| DC-link/GVDD | EVM exposes PVDD and GVDD feedback to its intended host. Each PVDD, phase-voltage and GVDD divider is 97.6 kΩ/3.01 kΩ (0.029917): 100 V maps to about 2.992 V; GVDD 20 V maps to about 0.598 V. | Fast local Vdc observation is available in principle, but the divided scale, ADC range, sample epoch and latency must be qualified at the selected host interface. It cannot be replaced by BMS UART data. |
| On-board protection | The retained schematic/BOM shows **no** local PVDD/GVDD/gross-current comparator or gate-clamp protection. J2 pin 14 `FAULT` only drives the board LED from the host. The guide's “PWM input forced 0%” action is reference-host firmware behavior. DRV8300 provides only bootstrap/GVDD UVLO; no `nFAULT` or thermal shutdown is available to credit. | The selected EVM supplies no independently acting system shutdown. Add and qualify an external independent protection/gate-inhibit path with defined power, reset/host-loss default, coverage and response. It must cover the derived fault set including charge-ineligible regeneration, failed host/adapter, logic-line fault, external wheel generation and board overtemperature; it does not prove physical energy isolation. |
| Hall interface | J7 provides 3.3-V Hall supply by default; `HALL_EXT` can supply an external level. R9/R10/R11 pull Hall A/B/C permanently to 3.3 V, independent of `HALL_PWR`. The motor observation used 5-V Hall supply and external 3.3-V pull-ups. | The planned, unverified installation configuration is J3=`HALL_EXT` with a qualified external 5-V supply only to Hall Vcc and retained EVM fixed 3.3-V pull-ups for the three Hall outputs. This matches the observed motor setup, but still requires common-return, output-level, backfeed and unpowered-host qualification. Do not assume an on-board 5-V rail or a 3.3-V host tolerates 5-V signals. |
| Temperature | The EVM's TMP235A2DBZR is an analogue board/FET-area temperature sensor beneath the FETs. | This supports board/FET thermal observation only. It is not the motor `Temp` pair: the observed 9.257-kΩ / 23.8 °C point does not identify an NTC curve, location, or fault coverage. |
| Zero/off and generated energy | Gate/PWM withdrawal controls switching only. A wheel-driven motor can still create back-EMF, body-diode/freewheel paths, DC-link rise, residual energy and drag/torque. | `PWM=0`, gate-off and `Iq*=0` are requests. Verify actual torque, current, voltage, energy destination and accessible-interface outcome in off, host-fault, BMS charge-ineligible and externally-driven-wheel cases. |

## Requirements fit and allocation impact

The following maps the requirements materially affected by the selection. It does not assign HMI, BMS, pack or retained mechanical-brake obligations to the EVM.

| Requirement / existing contract | Board fit | Required realization or qualification |
| --- | --- | --- |
| `REQ-SYS-TRQHW-001`; HW-I-003 | **Partial fit.** The bridge, three low-side shunts and local voltage feedback fit the selected topology. | Define the host/adapter pin map, ADC trigger/sample epochs, valid windows at the selected PWM/modulation range, reconstruction semantics, Vdc latency, calibration and board thermal/current envelope. Supply independently acting shutdown and separate physical-output/energy observation externally. |
| `REQ-SYS-ENE-002/003`, `REQ-SYS-FSC-005/006` (Draft) | **Augmentation required.** The selected EVM has no local comparator clamp or independent shutdown. | Establish an independent safe transition for host loss, off/fault, high-SOC/charge-ineligible regeneration and wheel drive. Characterize bus overvoltage, BMS path removal, body-diode paths, residual energy, external contacts and wheel restraint; do not credit a zero command or a BMS telemetry/status bit. |
| `REQ-SYS-BRK-001–005`, rear-light policy | **Compatible but not implementing the policy.** FOC accepts signed wheel-torque demand; no brake input or lamp output belongs to EVM. | Host arbitration must inhibit only positive torque on brake, preserve allowed accelerator-requested regeneration, and report active electrical braking only from qualified observed decelerating wheel torque. Hardware lamp default/full priority remains `HC-LAMP-DRIVE` work. |
| `REQ-SYS-TRQCTL-001`, `UR-TRACTION-CONTROL-001`, MCD-001 | **Compatible subject to timing.** Six PWM inputs and three shunts can serve Hall FOC. | Implement custom FOC: `Id*=0`, calibrated signed `Iq*`, bounded Hall-sector angle, shared saturation/anti-windup; no rider speed servo, hold current, forced alignment, sensorless fallback or field weakening. Verify PWM/gate timing, current-feedback coherence and failure response. |
| Motor Hall and temperature interface | **Conditional.** J7 and three Hall channels are present. The analogue TMP235 board/FET-area sensor is separate. | Qualify 5-V Hall supply / 3.3-V pullups and logic thresholds; map phases/Halls and calibrate sector/electrical offset. Independently characterize motor temperature sensor and protection path. |
| Pack/thermal/current envelope | **Constrained.** EVM is within nominal pack voltage, but TI's 25-A software-limited continuous-drive condition and the driver's 85-V recommended `SHx` condition are not qualified vehicle phase/DC ratings. | Derive limits from actual EVM MOSFET/connector/fuse/shunt/thermal measurements and the 40-A/10-A pack ceilings. Keep phase and battery currents distinct. Establish bus transient and thermal margin before any vehicle claim. |
| 40-km/h objective | **No resolution.** EVM selection does not provide motor voltage headroom. | Retain the MCD feasibility gate: reported 9.5 rpm/V implies about 55 V no-load at 40 km/h, while nominal pack voltage is 50.4 V and 58.8 V is only an outer cell-test reference. Characterize loaded voltage and modulation reserve through SOC/temperature/load; do not reduce the target silently. |

## Required integration contract

The [allocated traction HSI](DRV8300DRGE-EVM_WeAct_STM32H723VGT6_Traction_HSI.md) is the single vehicle signal, pin, epoch, inhibit and qualification contract.

## Open work and decision boundary

This selection supersedes only previous statements that no inverter is selected. It does not close the existing energy, motor, safety or architecture issues.  The controlled design must add an external shutdown/protection implementation; the eventual owner decision is needed only if that augmentation cannot meet the approved physical outcome without a requirement or architecture change.  No requirement is weakened by this board choice.
