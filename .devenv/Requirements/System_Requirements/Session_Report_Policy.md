# RidingControl session fault-report policy

**Type:** System Requirement. **Target:** `LE-RIDING`. These retained approved HMI report-policy requirements are Session obligations; RidingControl owns report selection, first-recognition order, priority, session lifetime and independent report monitoring/watchdog. BatteryStatus supplies reporting observations only, independently of operating-limit qualification. HMIControl encodes and transmits the selected report without changing selection, priority or retention.
