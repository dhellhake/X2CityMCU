## Brake priority and release

[REQ-VEH-BRK-001](../Abstract_Hardware_Requirements/Retained_Mechanical_Control.md#req-veh-brk-001) retains mechanical braking independence under the approved hardware allocation. The following EPCS behavior does not alter that obligation or select brake-input sensing.

## Resistance-coded brake-input information

The fixed passive shared two-wire interface is defined by [Brake_Input_Reference](../evidence/Brake_Input_Reference.md), [DEC-REF-002](../DEC-001_Decisions_and_Open_Issues.md#dec-ref-002) and PD `CON-010`. Only the handle/harness terminal interface is adopted; sensing and diagnostic realization remain downstream.
