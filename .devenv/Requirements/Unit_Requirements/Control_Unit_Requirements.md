# Control unit requirements

**Draft successor — 2026-09-16; retains REQ-001-R2.0.** Retained records keep their released bodies; the later Draft regular-DMA/Hall and fast-runtime refinements do not replace parent System verification.

| <a id="ur-demand-001"></a>`UR-DEMAND-001` | U-DEMAND-ARBITER / SC-DEMAND | Atomically form one `WheelTorqueRequest` signed rear-wheel demand from separately qualified/current `AcceleratorPosition`, `BrakeState`, active `ActiveRidingSettings`, `RidingAuthority`, sign-specific `BatteryCapabilityEnvelope` branches, `QualifiedMotion`, `ActualTractionOutput`, platform context/health and resolved active `DemandPolicyCalibration`. `requestedWheelTorqueNewtonMetres` is positive forward and carries a decision generation, matching authority generation and independent command expiry. Reject an absent, invalid, stale, incoherent, foreign-context/configuration or expired common contribution; reject independent authority expiry or generation mismatch; and withdraw to zero for any both-sign inhibition. An unavailable battery branch withdraws only its own sign and cannot enlarge it. Apply the active 0–5 profile, level-0 no-regen, provisional 35% neutral for levels 1–5, same-positive endpoints, active/hard 40-km/h both-sign cutoffs, lever positive-only block, per-sign capability ceilings, level-ramp/taper and the level-5 no-comfort-smoothing/low-speed-taper exception solely through activated resolved calibration. Post-stop regeneration remains disabled through hand-push travel until current qualified forward motion and actual positive applied wheel-torque estimate occur; a command/PWM/Hall state does not re-arm it. For each regenerative reduction episode retain the reduced ceiling while continuously moving in the regenerative range; exit from that range or qualified standstill qualifies recovery whether it occurs before or after clearance/partial relaxation, and automatic recovery follows once both qualification and a current cleared/relaxed branch exist. Keep that Demand state separate from Session fault restart and post-stop rearm. Publish reason/branch/recovery-generation only as service diagnostic; do not own settings activation, Session fault latch, battery protection, FOC or actual physical torque. | REQ-SYS-CTL-002 | `T-SW`, `A`, `T-FI`: every level/endpoint and neutral side; brake with accelerator regen; independent positive/negative partial limits and branch invalidity; hard/active speed cutoffs in both directions; current authority and command expiry independently; stale/foreign/configuration rollover; reset; simultaneous withdrawal/recovery; restriction episode exit/standstill before/after clearance; post-stop/hand-push/rearm using actual positive-output evidence; and diagnostic non-control isolation. Inspect command separately from physical output. Calibration owner must release and verify each profile, endpoint, ramp, taper, expiry/freshness/coherency bound and end-to-end transfer/response bound before implementation acceptance. |
| `UR-HMI-001` | U-HMI-ADAPTER / SC-HMI | For every outgoing VD18MT update form only parent-defined fields from selected report, usable charge and unsigned current magnitude/fallback, keeping internal validity separate; never treat initialization, loss or unqualified receipt as setting receipt or display acknowledgement. | REQ-SYS-CTL-003 | `T-SW`, `A`: fields/boundaries, invalid fallback, retained report, loss/restart and controlled-reference byte comparison. |
| `UR-LIGHT-001` | U-LIGHT-MODE / SC-LIGHT-POLICY | Retain valid current-session normal-light request initially Off and through communication loss; produce independent front/rear logical modes; select conservative rear Full for unqualified lever/braking information or parent Full triggers. | REQ-SYS-LGTPOL-001 | `T-SW`, `A`: all qualification combinations, normal changes during Full, loss/recovery and fresh session; compare brightness separately. |

| `UR-TEMPERATURE-QUALIFY-001` **Draft** | U-TEMPERATURE-QUALIFY / SC-TEMPERATURE-IF.V | Transform only completed vehicle regular raw motor and traction-board temperature records and accepted configuration into source-identified semantic temperature values, current quality and readiness. | <a id="ur-analog-acq-regular-001"></a>`UR-ANALOG-ACQ-REGULAR-001` **Draft** | U-ANALOG-ACQ-REGULAR / SC-ANALOG-ACQ.V | Own the regular-ADC DMA completed-buffer access. Associate each scan with its DMA sequence, completion timestamp, producer/configuration/reset context and error/overflow/cache state; never return a partial, overwritten, cache-incoherent, DMA-error or foreign-context scan as current acquisition. Preserve regular scan time separately from the fast epoch. | REQ-SYS-INP-002 | `T-SW`, `A`, `T-FI`: stream wrap, error, partial scans, cache coherency, reset and consumer freshness. |
| `UR-TRACTION-ACCEPT-001` | U-TRACTION-ACCEPT / SC-TRACTION-CTRL | Reject absent, invalid, expired or context-mismatched authority/command records. | `UR-HALL-CAPTURE-001` **Draft** | U-HALL-CAPTURE / SC-HALL-IF.V | Own Hall capture-ring access, sampled-state/edge association, capture-channel identity, extended timestamp, overflow/error/context handling and stable direct fast accessor. It does not use the vehicle analog regular-DMA or injected-JDR stores. | REQ-SYS-TRQPOS-001 | `T-SW`, `A`, `T-FI`: ring wrap, channel association, ambiguous edge, static state, error, cache and reset cases. |
| <a id="ur-hall-position-001"></a>`UR-HALL-POSITION-001` **Draft allocation of approved body** | U-HALL-POSITION / SC-HALL-IF.V | Consume only its current captured Hall sampled-state/edge evidence and a qualified configuration map/alignment; publish calibrated/aligned electrical rotor sector, direction and edge-time or unavailable. | <a id="ur-traction-control-001"></a>`UR-TRACTION-CONTROL-001` **Approved** | U-TRACTION-CONTROL / SC-TRACTION-CTRL | For accepted current authority/demand and qualified configuration, regulate calibrated `Iq*` with `Id*=0` from same-epoch valid phase-current feedback and bounded Hall angle; apply the common vector limit and anti-windup; publish requested and qualified actual-output/energy observations separately. Withhold torque realization when the required sample window, angle, voltage, configuration or authority is unavailable. | REQ-SYS-TRQCTL-001 | `T-SW`, `A`, `T-FI`: phase signs/epochs, saturated vectors, invalid sample windows, Hall seams/error bounds, rollback generation, boundary withdrawal and observation mismatch. |
| `UR-TRACTION-MOTION-001` **Draft** | U-TRACTION-MOTION / SC-TRACTION-CTRL | Publish `QualifiedMotion` from current Hall capture/position evidence, capture health, current context and released motion calibration/observability criteria independently of Ready, demand acceptance and actuation. | `UR-TRACTION-ACTUAL-OUTPUT-001` **Draft** | U-TRACTION-ACTUAL-OUTPUT / SC-TRACTION-CTRL | Publish `ActualTractionOutput` only as a qualified wheel-torque estimate from current post-stage physical evidence with source/timestamp/configuration provenance, same-operation phase-current/position and qualified motion, using activated `ActualOutputEstimationCalibration`. | <a id="ur-analog-acq-fast-001"></a>`UR-ANALOG-ACQ-FAST-001` **Draft** | U-ANALOG-ACQ-FAST / SC-ANALOG-ACQ.V | Be the direct ADC1/ADC2 JEOS/JDR raw-handler owner. | <a id="ur-traction-output-001"></a>`UR-TRACTION-OUTPUT-001` **Draft** | U-TRACTION-OUTPUT / SC-TRACTION-CTRL | Be the sole literal TIM8 compare/JSQR stage-commit writer. Accept `CCR1..3`, next commanded-vector ADC context and the `U-TRACTION-CONTROL`-calculated `CCR4` sampling plan only while current authority, valid fast feedback, Hall/configuration and observed hardware permit are current. Only in JEOS, with PRIMASK clear on entry and both ADCs observed disarmed, use one non-nested checked token scope. Recheck current context and non-latched safety state, set/readback UDIS before any compare store, write/readback CCR1..4 and slave-first/master-last JSQR, stage candidate next context after those readbacks, verify closing guard, arm/readback master, clear/readback UDIS last, mark armed-next context and execute the compiler-and-hardware completion barrier. It shall perform no FOC, polling, loop, logging, allocation, MOE/RUN_EN assertion, `UG` or later enable write in that scope. Any failure calls the project `safety_withdraw` with the live token, which latches/invalidate state, writes literal enable-safe images, sets UDIS and issues JADSTP without polling. It shall treat PWM/break state as command/interface observation, not proof of physical torque or energy outcome. | REQ-SYS-TRQEX-001, REQ-SYS-PLT-002 | `T-SW`, `A`, `T-FI`: late compare, timer update, UDIS/guard/rearm/readback failure, token nesting/lifetime, mask duration/barrier, pending break during commit, permit loss, reset, zero request and observed physical-outcome mismatch. |
| <a id="ur-platform-binding-001"></a>`UR-PLATFORM-BINDING-001` **Draft** | U-PLATFORM-BINDING / SC-PLATFORM.V | Configure and audit selected resource enables, static vector routes, priority classes, DMA/cache attributes and scheduler binding. Route regular DMA to U-ANALOG-ACQ-REGULAR, JEOS to U-ANALOG-ACQ-FAST, Hall capture to U-HALL-CAPTURE, and break/error to their direct owners. Own static checked fast-resource access and immediate fast inhibition; publish current condition/reason for Session and Service classification without owning their policy. NMI/HardFault have no shared-fast-resource/token access. A break pending during PRIMASK masking withdraws physical permit through hardware break/external inhibit; a fresh operation generation follows only the applicable clean restart. It shall not perform FOC calculation, polling wait or vehicle policy. | REQ-SYS-PLT-002 | `A`, `T-SW`, `T-FI`, `T-HW`: vector/priority routes, reset, token safety, bounded PRIMASK/barrier, pending break, cleanup, DMA cache/overflow, health classification and scheduler interaction. |
| `UR-PLATFORM-CALIBRATION-001` **Draft** | U-PLATFORM-CALIBRATION / SC-PLATFORM.V | Own static register/rank/trigger configuration identity and calibration lifecycle validity.
